# LLM 研究 Wiki

這是一套以繁體中文為主的 LLM 研究知識庫起始架構，採用 Karpathy「LLM Wiki」的持續累積式知識管理方式。

## 開始使用

1. 將整個資料夾放在本機專案目錄，建議使用 Git 管理版本。
2. 使用 Codex、Claude Code 或其他支援專案指令的 Agent 開啟此資料夾。
3. 先要求 Agent 閱讀 `AGENTS.md` 與 `index.md`。
4. 將論文、文章或文件放進 `raw/` 對應資料夾。
5. 告訴 Agent：「請依照 AGENTS.md 的 Ingest 流程處理這份資料，並整合到既有 Wiki。」
6. 使用 Obsidian 開啟本資料夾，可瀏覽 Markdown 頁面與知識圖譜。

## 三個重要檔案

- `AGENTS.md`：Agent 的工作規範與流程。
- `index.md`：知識庫的內容索引，建議每次研究任務先讀取。
- `log.md`：所有匯入、研究整理與健康檢查的時間紀錄。

## 使用原則

- `raw/` 保存原始證據，不任意修改。
- `wiki/` 保存整理後、可互相連結的知識。
- 不要只累積摘要；要持續更新概念頁、比較頁與綜合分析。
- 重要研究結論必須能追溯到原始來源。
- 初期不需要向量資料庫或複雜 RAG。資料量增加後，再評估全文搜尋或混合搜尋工具。
