# 原始資料 Raw Sources

此資料夾保存研究知識的原始依據。請依資料類型分類，盡可能保留原始檔名與版本。

## 分類
- `papers/`：學術論文、預印本與會議論文。
- `articles/`：技術文章、部落格與專題文章。
- `reports/`：白皮書、產業報告與研究報告。
- `documentation/`：官方技術文件、API 文件與專案文件。
- `datasets/`：資料集說明、資料字典與資料來源。
- `assets/`：圖片、圖表及其他附件。

## 命名建議
論文可使用 `年份_第一作者_短標題.pdf`；網頁可使用 `日期_網站_短標題.md`。若原始檔名有辨識價值，可保留原名。

## 原則
- 原始資料不可由 Agent 改寫或覆蓋。
- 記錄來源 URL、作者／機構、發布日期與存取日期。
- 無法取得全文時，明確標示實際閱讀範圍。
